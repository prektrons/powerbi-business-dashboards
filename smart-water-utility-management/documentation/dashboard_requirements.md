# Dashboard Requirements

## Dashboard Name

Smart Water Utility Intelligence Dashboard — South Korea

## Page 1 — Executive Overview

### Purpose

Provide a high-level view of water-quality conditions.

### KPIs

- Monitoring stations
- Measurements
- Average BOD
- Average COD
- Average DO
- Average pH
- High-risk stations

### Visuals

- KPI cards
- Water-quality trend
- Station risk ranking
- Parameter summary
- Geographic overview

### Analysis

### Filters

- Year

- Parameter
